videotools

small ffmpeg helpers for research videos

Convert

Batch re-encode many files to web-safe MP4 (H.264 + AAC, for Notion, Slack, GitHub). Rename with patterns, resize, HDR → SDR, GPU encoding.

Crop

Draw a box on a frame to cut out a region. Optional time trim. Even-pixel snapping and aspect presets.

Side by side

Crop, resize and place two videos next to each other (or anywhere on a canvas), with start offsets and labels.

Sync

Play two recordings together and tune the time offset frame by frame. Send the result to Side by side.

How it works

Each tool has three ways to produce the result:

  • Export in browser: decodes and encodes inside the browser (WebCodecs) and downloads the file. No server, no ffmpeg. The browser must be able to decode the input, which is true for most H.264 files but not for 10-bit HDR HEVC from iPhones.
  • Run on server: when the small job server runs on the machine that holds the videos, the page sends the ffmpeg command there and shows progress. Handles every format, uses the GPU.
  • Copy command: the ffmpeg command is always shown, so you can run it yourself.

Start the server (on the machine with the videos)

git clone https://github.com/whitealex95/videotools ~/Projects/videotools
python3 ~/Projects/videotools/server/videotools_server.py --root ~/Downloads --root ~/Projects

Needs only Python 3 and ffmpeg. The server listens on localhost:8765 and this page connects to it automatically.

Use it from another machine

ssh -N -L 8765:localhost:8765 cc-thunderbluff

The tunnel makes the remote server look like localhost:8765, so this page works unchanged. Or start the server with --host 0.0.0.0 and open http://<ip>:8765/ directly (it serves this same UI and prints a token).
